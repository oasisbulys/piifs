# PIIFS

π Institute for Inquiry and Fundamental Studies.

An independent catalogue of lectures and reading materials in General
Mathematics, Academic Mathematics, General Biology and Chemistry.

Plain HTML, CSS and vanilla JavaScript. No server, UI framework or installation
is required. Video recordings stream from their original YouTube publishers.
Publisher credits and source links accompany the lectures. Images, sources and
reuse terms are listed on the Image Credits page.

## GitHub Pages

In this repository, open **Settings → Pages**. Choose **Deploy from a branch**,
select the default branch and **/(root)**, then save. These files work at either
an account site or a repository site URL. The `.nojekyll` file preserves the
static files unchanged.

This repository contains only the public catalogue, display images and fonts.
It contains no local video downloads, private records or AI service.

## Science catalogue

Organic chemistry follows James S. Nowick's UC Irvine CHEM 51A course, with
David Van Vranken's CHEM 51B selections for hydrocarbons and selected Yale
CHEM 125a/125b lectures by J. Michael McBride as an optional conceptual companion.
Biology combines Paul Andersen's Bozeman Science lessons with the existing MIT,
Yale, UC San Diego and Stanford lectures. Plant Kingdom, Animal Kingdom and
Plant Growth and Development have their own chapters.

New lecture entries in `science-lectures.json` include a `sourceUrl` pointing to
the publisher's lesson page. Their video IDs, durations and embed availability
were checked on 8 November 2026. `chapterGuides` contains study guidance and
external reading links, including NCERT supplements for syllabus details and
diagrams. NCERT's PDFs could not be retrieved during this check; video playback
and external resources remain subject to their publishers' availability.
